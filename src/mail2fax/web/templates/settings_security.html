Absender-Whitelist

Nur Nachrichten dieser Absender lösen einen Faxversand aus – eine Adresse pro Zeile. Platzhalter sind erlaubt: *@example.com, fax-*@example.com. Ist die Liste leer, wird keine Nachricht verarbeitet.

Hinweis: Der Absender einer E-Mail lässt sich fälschen. Setzen Sie zusätzlich SPF/DKIM/DMARC-Prüfung auf dem Mailserver ein oder nutzen Sie ein Postfach, das nur aus dem internen Netz beliefert wird.
